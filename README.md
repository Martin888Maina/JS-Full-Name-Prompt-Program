# Full Name Input Application

A modern, interactive web application that demonstrates fundamental JavaScript user interaction patterns through a clean and elegant interface. This project showcases best practices in form handling, input validation, and user experience design.

**Live Demo:** [full-name-prompt.martinmaina.dev](https://full-name-prompt.martinmaina.dev)

## Overview

This application provides users with a simple yet polished interface to enter their first and last names. The program demonstrates core JavaScript concepts including DOM manipulation, event handling, form validation, and dynamic content generation.

## Features

- **Interactive Form Interface**: Clean and intuitive design for capturing user input
- **Real-time Validation**: Immediate feedback on user input to ensure data quality
- **Responsive Design**: Optimized viewing experience across desktop, tablet, and mobile devices
- **Smooth Animations**: Professional transitions and visual feedback enhance user engagement
- **Accessibility First**: Built with semantic HTML and ARIA attributes for screen reader compatibility

## Technologies Used

- **HTML5**: Semantic markup for structure and accessibility
- **CSS3**: Modern styling with flexbox, animations, and responsive design patterns
- **Vanilla JavaScript**: Pure JavaScript for all functionality, demonstrating core language competency without framework dependencies

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No additional dependencies or installations required

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Martin888Maina/JS-Full-Name-Prompt-Program.git
   ```

2. Navigate to the project directory:
   ```bash
   cd JS-Full-Name-Prompt-Program
   ```

3. Open the application:
   - Simply open `index.html` in your preferred web browser
   - Or use a local development server for the best experience

### Usage

1. Open the application in your browser
2. Enter your first name in the first input field
3. Enter your last name in the second input field
4. Click the "Submit" button or press Enter
5. Your full name will be displayed with a smooth animation
